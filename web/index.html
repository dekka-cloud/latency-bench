How far away is your server?

This page times how long your connection takes to reach the same small service running in different places, from connecting for the first time to loading a page that makes many calls one after another. It runs in your browser and sends nothing anywhere unless you choose to share the result.

Server First connection Round trip 20 calls in a row Download Upload

A first connection pays for finding the server, connecting and setting up encryption before anything loads, which the browser can't measure for the server that sent this page, since it's already connected to it. A round trip is one small request on a connection that's already open. Apps often make calls one after another, each waiting for the last, so the third column shows how distance adds up over twenty of them.
